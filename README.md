# SEED PATIENT VOICES — Concept Mock

患者さんへのインタビューや調査の気づきを、以下の共通構造で掲載するポータルサイトのHTMLモックです。

- 患者プロフィール **または** 疾患情報
- 4つのチャプター
- 調査概要・公開上の注意

## 開き方

`index.html` をブラウザで開いてください。CSS・JavaScriptはHTML内に含まれており、単体で動作します。外部通信が必要なのは「現在の公開サイト」へのリンクを開くときだけです。

## このモックに含まれるページ

- ポータルTOP
- 検索／入口タイプのフィルター
- 卵巣がん：患者プロフィール型＋4 Chapters
- 重症筋無力症：疾患情報型＋4 Chapters
- 文字サイズ切り替え
- 高コントラスト切り替え
- Mobileメニュー

## コンテンツ追加方法（モック段階）

HTML末尾の `libraryData` に1つのオブジェクトを追加すると、以下が自動生成されます。

- TOPのカード
- 検索対象
- 詳細ページ
- 目次
- 4つのチャプター
- 調査概要

本番では `libraryData` をJSON、ヘッドレスCMS、または管理画面のデータへ置き換え、表示テンプレートを共通化する想定です。

## Accessibility / Mobile

- Mobile-firstの1カラム設計
- 320px幅から横スクロールなし
- 本文16px以上、広めの行間
- 44px以上の主なタップ領域
- スキップリンク
- セマンティックな見出し・ランドマーク
- キーボード操作と明瞭なフォーカス表示
- 文字サイズ（標準／大／特大）
- 高コントラスト表示
- `prefers-reduced-motion` 対応
- 外部リンクの新規タブ表示を読み上げに通知

## コンテンツについて

このモックは、現在公開中の以下のSeed Planningサイトをもとに、検討用として要約・再構成しています。

- https://seed-planning.github.io/oc/
- https://seed-planning.github.io/mg/

卵巣がんサイトの既存5テーマは、共通4章テンプレートを確認するため、第4章に「患者さんが求めていた情報」と「再発への不安と心の支え」を統合しています。
